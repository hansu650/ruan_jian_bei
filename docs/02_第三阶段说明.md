# 第三阶段说明

第三阶段主题是“数据库模型与基础 CRUD”。本阶段只搭建数据底座，不提前实现 RAG、LLM、多智能体、学习画像生成、资源生成、智能辅导或测验批改。

## 阶段目标

- 接入 SQLite。
- 使用 SQLModel 建立最小业务模型。
- 启动后自动初始化数据库。
- 写入可重复运行的默认 seed 数据。
- 提供最小 CRUD API。
- 前端新增数据底座、课程管理和学生管理页面。
- 为后续课程知识库、学习画像、学习路径和资源生成预留数据结构。

## 为什么先用 SQLite

SQLite 不需要额外数据库服务，适合本地开发、课堂演示和比赛初赛验收。团队成员克隆仓库后，只要安装 Python 依赖并启动后端，就能自动生成本地数据库文件，避免 Docker、PostgreSQL 或远程数据库带来的环境不确定性。

默认数据库文件为：

```text
apps/api/eduforge.db
```

该文件已被 `.gitignore` 忽略，不提交仓库。

## 为什么使用 SQLModel

SQLModel 与 FastAPI、Pydantic 的使用方式接近，可以用较少代码完成 table model、schema 和类型检查，适合本阶段的最小 CRUD。后续如果项目复杂度上升，再评估是否加入 Alembic 迁移。

## 数据模型

### Student

学生基础信息，用于后续学习画像、学习路径和测验结果关联。

主要字段：

- `name`
- `major`
- `grade_level`
- `email`

### Course

课程基础信息。第三阶段默认 seed 一门《数据库系统》课程。

主要字段：

- `title`
- `description`
- `subject`
- `semester`

### KnowledgePoint

课程知识点，用于后续课程知识库、学习路径规划和资源生成。

主要字段：

- `course_id`
- `title`
- `chapter`
- `order_index`
- `summary`
- `difficulty`
- `prerequisites_json`

### ProfileDraft

画像草稿，只保存学生目标、薄弱点和偏好。本阶段不调用大模型，不生成真实 AI 画像。

主要字段：

- `student_id`
- `course_id`
- `goal`
- `background`
- `weak_points_json`
- `preferences_json`
- `mastery_json`
- `notes`

### ResourceItem

资源占位，用于后续资源生成模块。本阶段不生成讲义、思维导图、练习题或视频脚本正文。

主要字段：

- `course_id`
- `knowledge_point_id`
- `student_id`
- `resource_type`
- `title`
- `status`
- `content_preview`

## API 列表

学生：

- `GET /api/students`
- `POST /api/students`
- `GET /api/students/{student_id}`

课程：

- `GET /api/courses`
- `POST /api/courses`
- `GET /api/courses/{course_id}`

知识点：

- `GET /api/courses/{course_id}/knowledge-points`
- `POST /api/courses/{course_id}/knowledge-points`

画像草稿：

- `GET /api/profile-drafts`
- `POST /api/profile-drafts`

资源占位：

- `GET /api/resource-items`
- `POST /api/resource-items`

保留第二阶段接口：

- `GET /api/health`
- `GET /api/meta`

## Seed 数据

后端启动时会自动初始化数据库并写入默认数据：

- 默认学生：示例学生。
- 默认课程：数据库系统。
- 默认知识点：数据库基础、关系模型、SQL 基础、JOIN 与子查询、ER 建模、函数依赖与范式、事务与并发控制、索引与 B+ 树、查询优化、综合复习。
- 默认画像草稿：用于展示学生目标、薄弱点、偏好和掌握度字符串。
- 默认资源占位：讲义、思维导图、练习题、实操案例、视频脚本。

Seed 函数可以重复运行，不会无限重复插入默认数据。

## 前端页面

### /database

第三阶段数据底座状态页，展示：

- 学生数
- 课程数
- 知识点数
- 画像草稿数
- 资源占位数
- 默认学生
- 默认课程
- 数据库类型 SQLite
- ORM SQLModel

### /courses

课程管理页，展示课程列表和选中课程的知识点列表，并提供最小创建课程和创建知识点表单。

### /students

学生管理页，展示学生列表和画像草稿列表，并提供最小创建学生和创建画像草稿表单。
