# 环境准备说明

EduForge 智学工坊使用 Conda 管理 Python 环境，环境名固定为 `cnsoftbei_a3_eduforge`，Python 版本为 3.11。前端使用 Next.js、TypeScript、Tailwind CSS 和 pnpm。

## 后端环境

```powershell
conda create -n cnsoftbei_a3_eduforge python=3.11 -y
conda activate cnsoftbei_a3_eduforge
cd apps/api
python -m pip install --upgrade pip
pip install -r requirements.txt
pip install -r requirements-dev.txt
pip install -e .
```

`pip install -e .` 用于可编辑安装后端包，方便测试和本地开发时直接导入 `app`。

## 前端环境

Node.js 要求 `>= 20.9`，推荐 LTS。pnpm 可通过 Corepack 安装：

```powershell
corepack enable
corepack prepare pnpm@latest --activate
cd apps/web
pnpm install
```

## 启动

后端：

```powershell
cd apps/api
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

前端：

```powershell
cd apps/web
pnpm dev
```

## 第九阶段说明

第九阶段新增 TutorAgent 智能辅导和 CitationVerifier 轻量防幻觉校验，不需要新增依赖，不需要 API Key，不调用真实外部模型。

常见问题：

- `/tutor` 回答没有引用：先在 `/knowledge-base` 导入《数据库系统》示例资料。
- `/tutor` 个性化程度较低：先在 `/profile` 生成学习画像。
- 端口占用：关闭旧的 `uvicorn` 或 `pnpm dev` 进程。
- pnpm 未安装：执行 `corepack enable` 和 `corepack prepare pnpm@latest --activate`。
- 版权风险问题：系统会拒绝复制出版教材原文、教材 PDF 或扫描件。
