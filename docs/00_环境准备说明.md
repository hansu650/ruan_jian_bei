# 环境准备说明

本文面向 EduForge 智学工坊团队成员，说明本地开发环境、启动方式和常见问题。当前项目处于第八阶段：多类型学习资源生成 ResourceAgent。

## 基础环境

后端统一使用 Conda 管理 Python 环境：

```bash
conda create -n cnsoftbei_a3_eduforge python=3.11 -y
conda activate cnsoftbei_a3_eduforge
```

后端支持可编辑安装：

```bash
cd apps/api
pip install -r requirements.txt
pip install -r requirements-dev.txt
pip install -e .
```

## 前端环境

前端位于 `apps/web`，使用 Next.js、TypeScript、Tailwind CSS 和 shadcn/ui。要求：

- Node.js >= 20.9
- pnpm
- 推荐 Node.js LTS

安装 pnpm：

```bash
corepack enable
corepack prepare pnpm@latest --activate
```

安装依赖：

```bash
cd apps/web
pnpm install
```

## 启动服务

后端：

```bash
cd apps/api
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

前端：

```bash
cd apps/web
pnpm dev
```

访问地址：

- 前端首页：[http://localhost:3000](http://localhost:3000)
- 学习画像：[http://localhost:3000/profile](http://localhost:3000/profile)
- 学习路径：[http://localhost:3000/learning-path](http://localhost:3000/learning-path)
- 资源生成：[http://localhost:3000/resources](http://localhost:3000/resources)
- 后端 Swagger：[http://localhost:8000/docs](http://localhost:8000/docs)

## 数据库、知识库与资源

SQLite 数据库默认生成在 `apps/api/eduforge.db`，不提交 Git。

示例课程资料位于：

```text
data/sample_courses/database_system/
```

上传文件保存到 `apps/api/storage/uploads/`，不提交 Git。第八阶段生成资源会保存到 `GeneratedResource` 表，资源引用来源保存在 `citations_json` 字段中。

## LLM 与 Agent 环境

第八阶段仍然默认使用 MockLLM：

```env
USE_MOCK_LLM=true
LLM_PROVIDER=mock
LLM_MODEL=mock-edu-model
LLM_TIMEOUT_SECONDS=60
```

ResourceAgent 不调用真实外部 API，不需要 API Key，不产生费用。SparkProvider 仅为后续讯飞星火或科大讯飞相关工具接入预留。

## 常见问题

- `conda` 不是内部或外部命令：安装 Anaconda 或 Miniconda，并重新打开终端。
- `uvicorn` 命令不存在：确认安装了 `requirements.txt` 并激活正确 Conda 环境。
- 端口 8000 或 3000 被占用：关闭旧服务，或临时换端口启动。
- Node 版本过低：升级到 Node.js LTS，要求至少 20.9。
- pnpm 未安装：执行 `corepack enable` 和 `corepack prepare pnpm@latest --activate`。
- `/resources` 没有路径：先在 `/profile` 生成画像，再在 `/learning-path` 生成路径。
- 资源没有 citations：先在 `/knowledge-base` 导入《数据库系统》示例资料。

## 阶段边界

第八阶段只做 ResourceAgent、GeneratedResource、资源正文生成和 citations_json。不要在本阶段实现 TutorAgent、答题提交、自动批改、学习效果评估、路径动态调整、完整 RAG、embedding、ChromaDB 或真实模型调用。
