# 环境准备说明

本文面向 EduForge 智学工坊团队成员，说明本地开发环境、启动方式和常见问题。当前项目处于第七阶段：个性化学习路径 PlannerAgent。

## 基础环境

后端统一使用 Conda 管理 Python 环境：

```bash
conda create -n cnsoftbei_a3_eduforge python=3.11 -y
conda activate cnsoftbei_a3_eduforge
```

环境名 `cnsoftbei_a3_eduforge` 包含比赛、赛题和项目含义，方便团队成员识别。Python 使用 3.11，是因为 FastAPI、Pydantic v2、SQLModel、pytest、ruff 和 mypy 都能稳定支持。

后端支持可编辑安装：

```bash
cd apps/api
pip install -r requirements.txt
pip install -r requirements-dev.txt
pip install -e .
```

`pip install -e .` 可以让本地修改 `apps/api/app/` 后立即被测试和开发服务器识别。

## 前端环境

前端位于 `apps/web`，使用 Next.js、TypeScript、Tailwind CSS 和 shadcn/ui。要求：

- Node.js >= 20.9
- pnpm
- 推荐 Node.js LTS

安装 pnpm：

```bash
corepack enable
corepack prepare pnpm@latest --activate
```

安装前端依赖：

```bash
cd apps/web
pnpm install
```

## 启动服务

后端：

```bash
cd apps/api
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

前端：

```bash
cd apps/web
pnpm dev
```

访问地址：

- 前端首页：[http://localhost:3000](http://localhost:3000)
- 学习画像：[http://localhost:3000/profile](http://localhost:3000/profile)
- 学习路径：[http://localhost:3000/learning-path](http://localhost:3000/learning-path)
- 后端 Swagger：[http://localhost:8000/docs](http://localhost:8000/docs)

## 数据库与知识库

第三阶段开始使用 SQLite + SQLModel。默认数据库地址为 `sqlite:///./eduforge.db`，按当前启动方式会生成在 `apps/api/eduforge.db`。数据库文件属于本地运行产物，不提交 Git。

第四阶段示例课程资料位于：

```text
data/sample_courses/database_system/
```

这些 Markdown 文件为团队原创整理内容，可以提交 Git。上传文件保存到 `apps/api/storage/uploads/`，不提交 Git。

## LLM 与 Agent 环境

第五阶段开始使用 MockLLMProvider，默认配置为：

```env
USE_MOCK_LLM=true
LLM_PROVIDER=mock
LLM_MODEL=mock-edu-model
LLM_TIMEOUT_SECONDS=60
```

第七阶段 PlannerAgent 仍然只调用 MockLLM，不接真实外部 API，不需要 API Key，不产生费用。SparkProvider 仅为后续讯飞星火或科大讯飞相关工具接入预留。

## 常见问题

- `conda` 不是内部或外部命令：安装 Anaconda 或 Miniconda，并重新打开终端。
- `conda activate` 失败：先执行 `conda init powershell` 或在 Anaconda Prompt 中操作。
- PowerShell 执行策略限制脚本：以管理员身份执行 `Set-ExecutionPolicy RemoteSigned`，或临时使用 `powershell -ExecutionPolicy Bypass -File scripts/check-phase7.ps1`。
- `pip install` 失败：确认已激活 `cnsoftbei_a3_eduforge`，并升级 pip。
- `FastAPI` 或 `sqlmodel` 无法导入：重新执行后端依赖安装命令。
- `uvicorn` 命令不存在：确认安装了 `requirements.txt` 并激活正确 Conda 环境。
- 端口 8000 或 3000 被占用：关闭旧服务，或临时换端口启动。
- Node 版本过低：升级到 Node.js LTS，要求至少 20.9。
- pnpm 未安装：执行 `corepack enable` 和 `corepack prepare pnpm@latest --activate`。
- 学习路径生成提示没有画像：先在 `/profile` 页面生成示例学生的 8 维学习画像。

## 阶段边界

第七阶段只做 PlannerAgent、LearningPath、LearningPathStep、薄弱点覆盖检查和资源类型推荐。不要在本阶段实现 ResourceAgent、资源正文生成、智能辅导、测验批改、完整 RAG、embedding、ChromaDB 或真实模型调用。
