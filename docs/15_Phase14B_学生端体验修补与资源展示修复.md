# Phase 14B：学生端体验修补与资源展示修复

## 阶段目标

Phase 14B 聚焦学生端体验和内容展示稳定性，不新增 Agent、不新增数据库模型、不新增真实外部 API，也不生成最终交付材料。

本阶段重点修复：

- `/resources` 中 Markdown、SQL 代码块和 Mermaid 思维导图展示不稳定的问题。
- 资源列表预览直接截取 Markdown 原文，出现 `#`、代码围栏或 mermaid 源码的问题。
- `/learn` 学生首页中残留“演示数据”等后台视角文案的问题。
- `/analytics` 中学习诊断和补救建议展示不够学生友好的问题。
- 当前页面导航高亮不够明显的问题。
- spark-http 模式下批量生成资源容易误触多次真实模型调用的问题。

## Markdown 与 Mermaid 展示

资源正文继续通过 `MarkdownPreview` 展示，支持标题、段落、列表、表格、普通代码块、SQL 代码块和 Mermaid 代码块。

Mermaid 代码块交给 `MermaidDiagram` 在客户端渲染。渲染失败时，页面不会白屏，会显示“图表渲染失败，可查看源码”的兜底提示。

SQL 和普通代码块使用深色代码块样式，避免把资源正文呈现成大段原始文本。

## 资源预览修复

资源列表卡片不再直接截取 `content` 原文，而是先清理 Markdown 标题、链接、代码围栏、mermaid 和 SQL 代码块，再生成适合列表阅读的短摘要。

这样资源列表不会出现：

- `# 标题`
- ````sql`
- ````mermaid`
- 大段 Mermaid 源码

## Spark Lite 模式下的批量生成保护

`/resources` 默认只选择“讲义”资源类型。学生或演示者可以手动勾选更多资源类型。

如果当前是 spark-http 真实模式，并且选择了多个资源类型，页面会要求确认后才能批量生成，避免误触多次真实模型调用。

## 学生端文案修补

`/learn` 中的“演示数据基本就绪”调整为“学习流程基本就绪”，减少后台和演示视角，强调学生学习数据可以继续沉淀和使用。

## 学习评估展示

`/analytics` 继续用进度条展示知识点掌握度，并将补救建议展示为学习行动列表，而不是主视觉 JSON。

评估报告时间使用中文本地化展示，更适合学生阅读。

## 导航高亮

顶部导航和侧边栏的当前页面高亮进一步增强：

- 浅蓝背景
- 蓝色边框
- 加粗文字
- 图标同步变蓝

`/learn` 继续作为学生端第一入口，演示、测试和管理页面保持辅助定位。

## 本阶段没有做

- 没有新增 Agent。
- 没有新增后端业务功能。
- 没有修改 SparkHTTPProvider 调用逻辑。
- 没有自动触发真实 Spark 生成。
- 没有新增数据库模型。
- 没有生成 PPT、视频脚本或最终系统说明书。
- 没有提交 `.env`、数据库文件、上传目录或日志。

## 验收方式

建议检查：

1. `/resources` 中讲义资源能以 Markdown 排版展示。
2. `/resources` 中 mindmap 资源能渲染 Mermaid 图，失败时有兜底提示。
3. SQL 代码块显示清楚。
4. 资源列表摘要不再出现 Markdown 代码围栏。
5. `/resources` 默认只选择讲义，不默认全选 6 类资源。
6. spark-http 模式下多资源批量生成需要确认。
7. `/learn` 不再出现“演示数据基本就绪”这类后台视角文案。
8. `/analytics` 的补救建议是列表，不是 JSON 原文。
9. 当前导航高亮明显。
10. `pnpm lint` 和 `pnpm typecheck` 通过。
11. `pytest`、`ruff check .`、`mypy app tests` 通过。

一键检查：

```powershell
.\scripts\check-phase14b.ps1
```

```bash
./scripts/check-phase14b.sh
```
