# 第六阶段说明：对话式学习画像 ProfileAgent

第六阶段已经完成，目标是实现 A3 题面中的“对话式学习画像自主构建”。

## A3 要求

学生不通过传统繁琐表单，而是用自然语言描述专业、目标、基础、薄弱点、学习偏好和时间安排。系统自动抽取特征，构建不少于 6 个维度的动态学生画像。

## EduForge 8 维画像

- 专业背景
- 学习目标
- 知识基础
- 学习偏好
- 认知风格
- 易错点
- 时间约束
- 知识点掌握度

## 核心设计

- `LearnerProfile`：保存正式动态学习画像。
- `ProfileChatMessage`：保存画像构建过程中的对话消息。
- `AgentRun`：保存 ProfileAgent 运行记录。
- `ProfileAgent`：读取学生输入、已有画像和课程信息，调用 MockLLM，解析 JSON 并合并画像。

生成流程：

```text
学生输入 → ProfileAgent → MockLLM → JSON 解析 → 合并旧画像 → 保存 LearnerProfile → 返回前端
```

画像更新策略：

- 新消息有明确内容时更新对应字段。
- 新消息没提到的字段保留旧画像。
- list 字段去重合并。
- mastery 字段按新结果合并或覆盖。
- 不因为一次空输出清空旧画像。

## API

- `GET /api/learner-profiles`
- `GET /api/learner-profiles/{profile_id}`
- `POST /api/learner-profiles/chat`
- `GET /api/learner-profiles/summary/by-student-course`
- `GET /api/learner-profiles/dimension-check/by-student-course`
- `GET /api/agent-runs`

## 前端页面

`/profile` 页面支持选择学生和课程、发送自然语言描述、展示对话记录、8 维画像卡片、掌握度进度条、画像完成度和最近 ProfileAgent 运行记录。

## 边界

第六阶段没有实现完整多智能体、学习路径、资源生成、智能辅导、测验批改、RAG 或真实讯飞星火接入。系统只使用 MockLLM，不调用真实外部 API。

## 与第七阶段衔接

第七阶段已在第六阶段画像基础上实现 PlannerAgent。学习路径生成会读取 LearnerProfile 中的学习目标、薄弱点、学习偏好、时间约束和掌握度，用于生成阶段化学习计划。
