# 第六阶段说明

第六阶段名称：对话式学习画像 ProfileAgent。

## 第六阶段目标

本阶段实现 A3 赛题核心能力之一：学生通过自然语言对话描述专业、目标、知识基础、薄弱点、学习偏好和时间安排，系统自动抽取并更新动态学习画像。

## A3 题面要求

A3 要求不采用传统繁琐表单，而是通过对话方式构建学习画像，画像维度不少于 6 个，并能随着后续学习过程动态更新。

## 8 维画像设计

EduForge 当前实现 8 个维度：

- 专业背景
- 学习目标
- 知识基础
- 学习偏好
- 认知风格
- 易错点
- 时间约束
- 知识点掌握度

## ProfileAgent 设计

`ProfileAgent` 位于 `apps/api/app/agents/profile_agent.py`。它读取学生、课程、已有画像、画像草稿和近期画像对话，调用 MockLLM 的 profile 场景，解析 JSON 输出，并在解析失败时使用关键词 fallback 抽取。

当前只实现 ProfileAgent，不实现完整多智能体框架，不引入 LangGraph、LangChain 或其他 Agent 框架。

## 数据模型

- `LearnerProfile`：保存最新 8 维动态画像，同一个学生和课程维护一条最新画像。
- `ProfileChatMessage`：保存画像构建过程中的 user / assistant / system 消息。
- `AgentRun`：保存 ProfileAgent 运行记录，包括 agent_name、输入预览、输出预览、状态、延迟和 llm_log_id。

## 画像生成流程

学生输入 → ProfileAgent → MockLLM → JSON 解析 → fallback 校验 → 合并旧画像 → 保存 LearnerProfile → 保存 ProfileChatMessage → 保存 AgentRun → 返回前端。

## 画像更新策略

- 新消息中有明确内容时更新对应字段。
- 新消息没有提到的字段保留旧画像。
- list 字段去重合并。
- mastery 字段按新结果合并或覆盖。
- 已有画像更新时 version 自增。
- 不因为一次空输出清空旧画像。

## 版权边界

- 不复制出版教材原文。
- 不处理教材 PDF 或扫描件。
- 只使用合法资料和团队原创整理内容。
- 如果用户请求复制教材原文，ProfileAgent 会在 assistant_message 中提醒合法资料边界。

## API 列表

- `GET /api/learner-profiles`
- `GET /api/learner-profiles/{profile_id}`
- `POST /api/learner-profiles/chat`
- `GET /api/learner-profiles/summary/by-student-course`
- `GET /api/learner-profiles/dimension-check/by-student-course`
- `GET /api/agent-runs`

## 前端页面

`/profile` 页面支持：

- 选择学生和课程。
- 使用示例输入快速生成画像。
- 聊天式画像构建。
- 展示 8 维画像卡片。
- 展示知识点掌握度进度条。
- 展示画像完成度。
- 展示最近 ProfileAgent 运行记录。
