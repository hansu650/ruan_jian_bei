# Phase 16A：全站 UI V2 大重构

## 阶段目标

Phase 16A 的目标不是继续堆叠业务功能，而是把 EduForge 从“功能模块集合”进一步重构为“成熟学生学习平台”。本阶段重点重写前端外壳、学生端主入口和核心学习页面布局，让评委和学生第一眼看到的是学习旅程，而不是后台控制台。

本阶段不新增后端业务能力、不新增 Agent、不修改数据库模型、不修改 SparkHTTPProvider 真实调用逻辑，也不触发真实 Spark 生成。

## 为什么要做 UI V2

前几阶段已经完成了知识库、画像、路径、资源、辅导、测验和评估的学习闭环，但旧界面仍容易呈现为研发控制台或演示面板。比赛现场更需要一个清晰的学生端产品入口：

- 学生知道当前在学什么课程。
- 学生知道今天该做什么。
- 学生能看到学习进度、薄弱点和下一步行动。
- 评委能快速理解多智能体协作与创新点。
- 演示、测试和管理工具被保留，但不抢学生主入口。

## 参考原则

本阶段只借鉴成熟开源模板和学习平台的布局思路，不复制代码、文案、图片、Logo 或页面：

- 借鉴 shadcn / Tailwind dashboard 的 app shell、侧边栏、卡片层级和留白。
- 借鉴 LMS 学习平台的“我的课程、继续学习、章节进度、当前任务”结构。
- 借鉴 AI 学习产品的学习路径、智能辅导、练习反馈和 Agent 协作呈现。
- 不虚构未实现能力，不宣称 CrewAI、LangGraph、完整 BKT、情感识别、费曼学习法或多 Agent 辩论已实现。

## 新版学习产品风格

UI V2 采用低噪音学习产品风格：

- 左侧固定学生导航，右侧主内容区。
- 顶部栏只显示当前课程、当前学生和模型模式小提示。
- 主色使用低饱和蓝 / 天蓝，背景使用浅灰，卡片使用白底、细边框和轻阴影。
- 页面标题、主按钮、空状态和错误状态保持一致。
- 学生学习页面减少 Phase、API、AgentRun 等工程词，优先使用学生能理解的语言。

## 全局 App Shell

新增 V2 组件：

- `components/v2/app-shell.tsx`
- `components/v2/student-sidebar.tsx`
- `components/v2/student-topbar.tsx`
- `components/v2/page-container.tsx`
- `components/v2/page-hero.tsx`
- `components/v2/section-card.tsx`
- `components/v2/stat-card.tsx`
- `components/v2/status-pill.tsx`

导航优先级调整为：

1. 学习中心：学习工作台、学习画像、学习路径、学习资源、智能辅导、练习测验、学习评估。
2. 课程资料：知识库。
3. 项目亮点：智能体协作、创新亮点。
4. 演示与测试：演示工作台、测试清单。
5. 项目管理：Dashboard、数据底座、课程管理、学生管理、模型实验室、Health。

当前页面使用浅蓝背景和蓝色文字高亮，避免用户不知道自己处于哪个学习环节。

## 首页 `/`

首页重构为正式产品入口，突出：

- EduForge 智学工坊。
- 面向高校课程的 AI 个性化学习助手。
- 画像 → 路径 → 资源 → 答疑 → 练习 → 评估的学习闭环。
- 主按钮进入 `/learn`，次按钮进入 `/demo`。

首页不再呈现为开发骨架或调试页。

## 学习工作台 `/learn`

`/learn` 是学生第一入口。新版页面围绕“今天继续学习什么”组织信息：

- 顶部欢迎卡片：学生、课程、学习目标、当前薄弱点状态。
- 今日学习任务：推荐步骤、推荐理由、预计用时、相关薄弱点和下一步按钮。
- 学习旅程：画像、路径、资源、辅导、练习、评估。
- 右侧概览：薄弱点、路径步骤数、资源数量、测验次数、平均准确率、最近结果。

学习数据来自后端 API，不使用 localStorage 存储学生核心学习数据。

## 学习资源 `/resources`

资源页重构方向是“学习资料库”，不是“资源生成后台”：

- 学习上下文选择区更轻量。
- 资源类型以中文卡片呈现。
- 默认只选择讲义，避免真实模型模式下误触批量生成。
- 一键生成多类型资源在真实模型模式下保留确认。
- 资源列表使用资料卡片展示中文类型、标题、摘要、引用数量和状态。
- 资源详情继续使用 Markdown / Mermaid / SQL 代码块 / CitationList 展示。

## 智能体协作 `/agents-flow`

`/agents-flow` 用于比赛讲解系统架构。页面展示真实已实现的协作链路：

ProfileAgent → PlannerAgent → ResourceAgent → TutorAgent → PracticeAgent → EvaluatorAgent，并由 CitationVerifier 参与资源和答疑可信校验。

该页面只说明当前自研轻量 Agent 流水线，不宣称接入 CrewAI、LangGraph 或复杂调度平台。

## 创新亮点 `/innovation`

`/innovation` 将真实能力包装为评委容易理解的亮点：

- 画像驱动的个性化学习闭环。
- 可信课程知识库与引用来源。
- 多智能体学习流水线。
- 六类个性化学习资源生成。
- 轻量掌握度追踪与学习效果评估。
- Mock / Spark 双模式。
- 防幻觉与内容安全。

页面同时保留“不虚假宣传边界”，明确 BKT、情感识别、费曼学习法、多 Agent 辩论等只作为后续扩展方向。

## 本阶段没有做

- 没有新增后端业务功能。
- 没有新增 Agent。
- 没有修改数据库模型。
- 没有修改 SparkHTTPProvider 真实调用逻辑。
- 没有触发真实 Spark 生成。
- 没有生成最终 PPT、视频脚本或系统说明书终稿。
- 没有复制其他开源项目代码或素材。

## 验收方式

自动检查：

```powershell
python scripts/check-env.py
.\scripts\check-phase16a.ps1
```

手动检查：

1. `/` 像正式产品首页，主按钮进入 `/learn`。
2. `/learn` 第一眼像学生学习首页，有今日任务、继续学习、学习进度和薄弱点。
3. `/resources` 像学习资料页面，Markdown、Mermaid、SQL 代码块和引用来源展示正常。
4. `/tutor` 像 AI 辅导页，引用和可信状态清楚。
5. `/practice` 像在线小测，批改反馈清楚。
6. `/analytics` 像学习诊断报告，不以 raw JSON 为主视觉。
7. `/agents-flow` 能清楚展示多智能体协作链路。
8. `/innovation` 创新点有说服力，且不虚构未实现能力。
9. 导航中 `/learn` 优先，当前页高亮明显，演示/测试/管理入口降级。
10. 页面和文档不包含真实密钥，自动化测试不真实调用 Spark。
