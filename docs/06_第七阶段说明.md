# 第七阶段说明：个性化学习路径 PlannerAgent

## 阶段目标

第七阶段实现 A3 赛题核心能力之一：个性化学习路径规划和资源推送。系统结合学生画像、课程知识点、学习进度、知识掌握情况和学习偏好，生成阶段化学习路径，明确学习步骤、顺序、知识点、预计耗时、推荐资源类型和掌握标准。

本阶段只做学习路径规划和资源类型推荐，不生成具体资源内容。

## A3 题面对应要求

A3 要求系统根据学生专业、学习进度、知识掌握情况和学习偏好，为学生规划科学、动态的个性化学习路径，并基于画像实现文档、视频、题库、实操案例等资源类型的精准推送。

## 学习路径设计

后端新增两个数据模型：

- `LearningPath`：一次学习规划结果，包含学生、课程、画像、目标天数、策略摘要、薄弱点和整体推荐资源类型。
- `LearningPathStep`：路径中的阶段步骤，包含顺序、学习目标、知识点、前置要求、预计耗时、推荐资源类型、学习活动和掌握标准。

资源类型使用字符串保存：

- `lecture_note`：讲义
- `mindmap`：思维导图
- `quiz`：练习题
- `reading`：拓展阅读
- `practice_case`：实操案例
- `video_script`：视频脚本

## PlannerAgent 设计

PlannerAgent 输入：

- LearnerProfile
- Student
- Course
- KnowledgePoint 列表
- 少量 DocumentChunk 摘要
- target_days

PlannerAgent 输出：

- 路径标题
- 学习目标
- 目标天数
- 策略摘要
- 薄弱点列表
- 推荐资源类型
- 阶段步骤列表
- 每步掌握标准

PlannerAgent 会调用 MockLLM 的 `learning_path` 场景。若模型返回 JSON 解析失败，系统使用 fallback 规划算法，基于课程知识点顺序和画像薄弱点生成约 7 个步骤。

## 生成流程

```text
学习画像
→ PlannerAgent
→ MockLLM
→ JSON 解析
→ fallback 规划兜底
→ 保存 LearningPath
→ 保存 LearningPathStep
→ 记录 AgentRun
→ 返回前端
```

## 薄弱点覆盖检查

`/api/learning-paths/{path_id}/plan-check` 会检查：

- 实际步骤数是否达到要求
- 画像中的薄弱点是否出现在路径步骤中
- 已覆盖和未覆盖的薄弱点
- 总预计学习时长
- 路径中推荐过的资源类型

默认画像中的 JOIN、事务隔离级别、B+ 树索引和查询优化会被优先覆盖。

## API 列表

- `POST /api/learning-paths/generate`
- `GET /api/learning-paths`
- `GET /api/learning-paths/{path_id}`
- `GET /api/learning-paths/{path_id}/steps`
- `GET /api/learning-paths/{path_id}/plan-check`
- `GET /api/agent-runs?agent_name=PlannerAgent`

如果没有学习画像，生成接口会返回 400，并提示“请先生成学习画像”。

## 前端页面

`/learning-path` 页面提供：

- 学生和课程选择
- 画像状态卡片
- target_days 输入
- 生成个性化学习路径按钮
- 历史路径列表
- 路径详情与步骤时间线
- 推荐资源类型说明
- 薄弱点覆盖检查

页面会在没有画像时提示先前往 `/profile` 生成学习画像。

## 版权边界

系统只使用合法资料和团队原创整理内容规划学习路径，不复制出版教材原文，不处理教材 PDF 或扫描件，不要求模型复述教材正文。

## 验收方式

后端：

```bash
cd apps/api
pytest
ruff check .
mypy app tests
```

前端：

```bash
cd apps/web
pnpm lint
pnpm typecheck
```

根目录：

```bash
python scripts/check-env.py
.\scripts\check-phase7.ps1
```

手动演示：

1. 打开 `/profile` 生成 8 维学习画像。
2. 打开 `/learning-path`。
3. target_days 设置为 7。
4. 点击生成个性化学习路径。
5. 检查 6-8 个步骤是否覆盖 JOIN、事务隔离级别、B+ 树索引等薄弱点。
6. 检查每个步骤是否展示推荐资源类型和掌握标准。
7. 检查 AgentRun 中是否记录 PlannerAgent。
