# A3 赛题摘要

## 赛题名称

A3 - 基于大模型的个性化资源生成与学习多智能体系统开发

## 出题企业

科大讯飞股份有限公司

## 业务背景

高校学生面对大量课程资料、学术资料和学习辅助工具时，常常难以快速找到适合自己的学习资源。不同学生的专业背景、知识基础、学习目标、学习偏好、学习能力和学习节奏不同，传统统一化教学和普通学习系统难以满足个性化学习需求。

本赛题要求面向高等教育个性化学习场景，基于大模型、多智能体、多模态资源生成、RAG 知识库和 AI 辅助开发等技术，开发一个能为学生生成个性化学习资源、规划学习路径、提供智能辅导和学习效果评估的智能体系统。

## 核心问题

- 如何通过自然语言对话构建学生画像，而不是依赖繁琐表单。
- 如何根据学生画像和课程知识库生成个性化学习资源。
- 如何体现多智能体协同，而不是单一问答机器人。
- 如何动态规划学习路径并根据学习效果调整推荐策略。
- 如何降低大模型幻觉，确保学习内容有依据、可追溯。
- 如何在演示中呈现清晰、美观、流畅的 AI 产品交互体验。

## 必做功能

1. 对话式学习画像自主构建。
2. 多智能体协同的资源生成。
3. 至少生成 5 种个性化学习资源。
4. 个性化学习路径规划和资源推送。
5. 构造至少一门完整高校专业课程的初始知识库或文档集。
6. 明确多智能体协同框架。

## 可选加分项

- 智能辅导：学生学习过程中可提问，系统即时答疑。
- 学习效果评估：跟踪练习结果、资源使用情况和反馈数据，评估知识点掌握度。
- 多模态资源生成：输出图解、短视频讲解脚本、动画脚本等更丰富的资源形式。

## 非功能要求

- 界面美观、简洁、交互清晰。
- 支持流式输出、Markdown 渲染、多模态内容卡片化展示、生成进度追踪等现代 AI 产品体验。
- 使用开源项目或 AI 工具时，需要在文档中标注名称、来源和协议。
- 系统需要具备防幻觉和内容安全过滤机制。
- 智能体核心功能响应时间应控制在合理范围内。
- 多模态资源生成不能长时间白屏，需要有进度提示或流式呈现。

## 实现条件

- 开发环境、编程语言、数据库、编辑器、硬件平台不限。
- 智能体开发框架不限。
- 系统中需要明确多智能体协同框架。
- 团队需要自行构造至少一门完整高校专业课程的初始知识库或文档集作为系统输入。
- EduForge 后续计划使用《数据库系统》作为第一门示例课程。

## 初赛提交材料

- 演示 PPT。
- 可完整运行的多智能体相关文件，包括源码、数据集、模型配置文件等。
- 智能体演示视频，时长控制在 7 分钟内。
- 智能体开发类型不限，可以是 Web 应用、移动端、小程序等。
- 配套文档，包括系统开发说明书、测试说明书等。
- 如果使用 AI Coding 工具，需要给出相关说明。

## 评分项

- 创新价值与实用性：35%
- 功能实现及技术要求：45%
- 配套文档丰富度：10%
- 演示视频和 PPT 效果：10%

## EduForge 对赛题要求的对应关系

| A3 要求 | EduForge 对应设计 |
| --- | --- |
| 对话式学习画像 | ProfileAgent + 8 维画像 |
| 多智能体协同 | ProfileAgent、RetrieverAgent、PlannerAgent、ResourceAgent、TutorAgent、PracticeAgent、EvaluatorAgent、VerifierAgent |
| 至少 5 类资源 | 讲义、思维导图、练习题、拓展阅读、实操案例、视频脚本 |
| 学习路径规划 | PlannerAgent 生成阶段化学习路径 |
| 智能辅导 | TutorAgent + RAG + 引用来源 |
| 学习效果评估 | PracticeAgent + EvaluatorAgent + 掌握度更新 |
| 防幻觉 | RetrieverAgent + VerifierAgent + citations |
| 生成进度 | task_id + 前端进度展示，后续阶段实现 |

## 第一阶段边界

第一阶段只进行环境准备、目录初始化、依赖文件、Conda 脚本、环境自检脚本、README 和基础规范文档建设。当前不实现正式业务功能，不实现学习画像、多智能体、RAG、资源生成、学习路径、测验批改或课程知识库。
