# 开发规范

本文约定 EduForge 智学工坊项目的工程协作规范。当前项目处于第七阶段：个性化学习路径 PlannerAgent。

## 分支与提交

分支命名：

- `feat/xxx`
- `fix/xxx`
- `docs/xxx`
- `refactor/xxx`

Commit Message 建议：

```text
feat: add health check
docs: add environment guide
chore: initialize project structure
feat: add planner agent
```

## Python 代码规范

- 使用类型注解。
- 保持函数短小，复杂业务放入 `services/` 或 `agents/`。
- `main.py` 只负责创建 FastAPI app、配置中间件、注册路由和 lifespan。
- 路由放在 `app/routers/`，schema 放在 `app/schemas/`。
- 数据库模型集中放在 `app/db/models.py`。
- 数据库 session、engine 和初始化放在 `app/db/database.py`。
- seed 数据放在 `app/db/seed.py`。
- 使用 `ruff check .` 和 `mypy app tests` 做质量检查。

## Agent 规范

- 第六阶段只实现 ProfileAgent。
- 第七阶段只实现 PlannerAgent。
- PlannerAgent 只生成学习路径和资源类型推荐，不生成资源正文。
- Agent 运行记录写入 `AgentRun`，输入输出只保存 500 字以内预览。
- 不在 Agent 中打印、保存或返回 API Key。
- 不引入 LangChain、OpenAI SDK、ChromaDB、sentence-transformers、torch 等重依赖。
- 不实现完整多智能体编排，后续按阶段逐步接入 ResourceAgent、TutorAgent 等。

## PlannerAgent 边界

PlannerAgent 的职责：

- 读取 Student、Course、LearnerProfile。
- 读取课程 KnowledgePoint。
- 可读取少量 DocumentChunk 摘要作为课程上下文。
- 调用 MockLLM 的 `learning_path` 场景。
- 解析 JSON，失败时使用 fallback 规划算法。
- 保存 LearningPath 和 LearningPathStep。
- 计算薄弱点覆盖情况。

PlannerAgent 不做：

- 不生成讲义、思维导图、练习题、实操案例或视频脚本正文。
- 不实现 ResourceAgent。
- 不做智能辅导或测验批改。
- 不做完整 RAG 问答。
- 不调用真实外部模型 API。

## FastAPI 路由规范

- 路由统一使用 `/api` 前缀。
- 找不到资源时返回 404。
- 缺少学习画像时，学习路径生成返回 400，并提示先生成学习画像。
- Router 保持薄层，复杂逻辑放入 service。
- 创建接口使用 `XxxCreate` 或 request schema，返回接口使用 `XxxRead` 或 response schema。

## 数据与版权规范

- 不提交本地 SQLite 数据库文件。
- 不提交 `.chroma` 或向量库持久化目录。
- `data/sample_courses/database_system/` 只存放团队原创整理的 Markdown 资料。
- 不提交出版教材 PDF、扫描件、电子书、出版社配套资料或教材原文摘录。
- 上传文件保存到 `apps/api/storage/uploads/`，不提交 Git。

## TypeScript 与前端规范

- 使用 TypeScript，避免用 `any` 逃避类型设计。
- API 请求封装在 `apps/web/lib/api.ts`。
- 类型定义放在 `apps/web/lib/types.ts`。
- 常量放在 `apps/web/lib/constants.ts`。
- 页面用 `useState` 和基础 React hooks 即可，不引入复杂状态库。
- 不引入 axios、react-query、图表库、认证库或 AI SDK。
- shadcn/ui 仅保留必要基础组件，不一次性添加大量组件。

## 前端页面规范

- 页面风格保持比赛演示导向，清晰、稳定、不过度装饰。
- 后端关闭时页面不能白屏，要显示 Alert。
- loading 状态使用 Skeleton。
- `/learning-path` 页面只展示路径、步骤、覆盖检查和资源类型推荐，不展示资源正文生成结果。

## 环境变量与密钥

- 使用 `.env` 保存本地配置。
- 仓库只提交 `.env.example`。
- 不提交真实 `.env`。
- 不在日志、响应、README 或测试中输出真实 API Key。
- 当前阶段默认 `USE_MOCK_LLM=true`，无需真实模型密钥。
