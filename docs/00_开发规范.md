# 开发规范

本文约定 EduForge 智学工坊项目的工程协作规范。当前项目处于第八阶段：多类型学习资源生成 ResourceAgent。

## 分支与提交

- `feat/xxx`
- `fix/xxx`
- `docs/xxx`
- `refactor/xxx`

Commit Message 示例：

```text
feat: add resource agent
docs: update phase eight guide
fix: repair generated resource API
```

## Python 代码规范

- 使用类型注解。
- `main.py` 只负责创建 FastAPI app、配置中间件、注册路由和 lifespan。
- 路由放在 `app/routers/`，schema 放在 `app/schemas/`。
- 业务逻辑放入 `app/services/`。
- Agent 逻辑放入 `app/agents/`。
- 使用 `ruff check .` 和 `mypy app tests` 做质量检查。

## Agent 规范

- ProfileAgent 只负责对话式学习画像。
- PlannerAgent 只负责学习路径规划和资源类型推荐。
- ResourceAgent 只负责生成资源正文和 citations。
- AgentRun 只保存 500 字以内预览，不保存 API Key 或超长敏感输入。
- 不引入 LangChain、OpenAI SDK、ChromaDB、sentence-transformers、torch 等重依赖。
- 不实现完整多智能体编排，后续按阶段逐步接入 TutorAgent、PracticeAgent、EvaluatorAgent 等。

## ResourceAgent 边界

ResourceAgent 可以：

- 读取 Student、Course、LearnerProfile、LearningPathStep。
- 检索 DocumentChunk 作为引用来源。
- 生成 lecture_note、mindmap、quiz、reading、practice_case、video_script。
- 保存 GeneratedResource。
- 保存 citations_json。
- 记录 ResourceAgent 的 AgentRun。

ResourceAgent 不做：

- 不做智能辅导聊天。
- 不做答题提交。
- 不做自动批改。
- 不做学习效果评估。
- 不做路径动态调整。
- 不调用真实外部模型 API。

## 前端规范

- 页面用 `useState` 和基础 React hooks 即可。
- API 请求封装在 `apps/web/lib/api.ts`。
- 类型定义放在 `apps/web/lib/types.ts`。
- 不引入 axios、react-query、复杂状态管理、图表库、认证库或 AI SDK。
- `/resources` 页面只展示资源生成、正文、citations 和 AgentRun，不做辅导或批改交互。

## 数据与版权规范

- 不提交本地 SQLite 数据库文件。
- 不提交上传目录。
- 示例课程资料必须是团队原创整理内容。
- 不提交出版教材 PDF、扫描件、电子书、出版社配套资料或教材原文摘录。
- 资源生成内容不得要求复制出版教材原文。
