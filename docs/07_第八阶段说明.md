# 第八阶段说明：多类型学习资源生成 ResourceAgent

第八阶段已完成 ResourceAgent 和 GeneratedResource，支持从学习路径 step 生成 6 类个性化学习资源：

- `lecture_note` 讲义
- `mindmap` 思维导图
- `quiz` 练习题资源
- `reading` 拓展阅读
- `practice_case` SQL/代码实操
- `video_script` 视频脚本

资源生成会结合：

- LearnerProfile
- LearningPathStep
- Course
- DocumentChunk 检索结果

每个资源保存 `citations_json`，用于记录来源 chunk。该阶段只做资源正文生成，不做智能辅导聊天、学生答题提交、自动批改或学习效果评估。

## API

- `GET /api/generated-resources/types`
- `POST /api/generated-resources/generate`
- `POST /api/generated-resources/generate-for-step`
- `GET /api/generated-resources`
- `GET /api/generated-resources/{resource_id}`

## 前端页面

- `/resources`

## 与第九阶段衔接

第九阶段在资源生成之后增加 TutorAgent。TutorAgent 可以选择某个 GeneratedResource 作为辅助上下文，但不会修改资源内容，也不会做自动批改。

## 版权边界

资源内容只基于合法资料和团队原创整理内容生成，不复制出版教材原文，不处理教材 PDF 或扫描件。
