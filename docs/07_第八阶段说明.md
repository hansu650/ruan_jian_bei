# 第八阶段说明：多类型学习资源生成 ResourceAgent

## 阶段目标

第八阶段实现 A3 题面中的“多智能体协同的资源生成”基础能力。系统根据学生画像、学习路径步骤、课程知识点和知识库检索 chunk，生成个性化学习资源。

本阶段只做资源内容生成，不做智能辅导、答题提交、自动批改或学习效果评估。

## 支持资源类型

- `lecture_note`：专业课程讲义
- `mindmap`：知识点思维导图
- `quiz`：练习题
- `reading`：拓展阅读材料
- `practice_case`：SQL/代码实操案例
- `video_script`：短视频/动画讲解脚本

如果前端不引入 mermaid 渲染库，mindmap 以 Markdown fenced code block 展示：

````text
```mermaid
mindmap
  root((事务与并发控制))
```
````

## 数据模型

`GeneratedResource` 保存资源生成结果：

- student_id
- course_id
- profile_id
- path_id
- step_id
- resource_type
- title
- content_format
- content
- citations_json
- status
- source
- llm_log_id

`citations_json` 保存来源 chunk 信息，包括 chunk_id、document_id、filename、chunk_index、section_title 和 quote_preview。

## ResourceAgent 设计

输入：

- Student
- Course
- LearnerProfile
- LearningPath
- LearningPathStep
- DocumentChunk 检索结果
- resource_type

输出：

- 资源标题
- 资源正文
- content_format
- citations

生成流程：

```text
学习路径 step
→ 检索课程知识库 chunk
→ ResourceAgent
→ MockLLM 场景调用
→ 模板化资源正文兜底
→ 保存 GeneratedResource
→ 记录 LLMCallLog
→ 记录 AgentRun
→ 前端展示正文与 citations
```

## API 列表

- `GET /api/generated-resources/types`
- `POST /api/generated-resources/generate`
- `POST /api/generated-resources/generate-for-step`
- `GET /api/generated-resources`
- `GET /api/generated-resources/{resource_id}`
- `GET /api/agent-runs?agent_name=ResourceAgent`

## 前端页面

`/resources` 页面提供：

- 学生和课程选择
- 学习画像摘要
- 学习路径和步骤选择
- 资源类型多选
- 一键生成选中资源
- 资源正文查看
- citations 引用来源查看
- ResourceAgent 运行记录

## 本阶段没有实现

- TutorAgent
- PracticeAgent
- EvaluatorAgent
- VerifierAgent
- 智能辅导聊天
- 答题提交
- 自动批改
- 学习效果评估
- 路径动态调整
- 完整多智能体编排
- 真实 RAG 问答
- embedding
- ChromaDB
- 真实讯飞星火接入

## 版权边界

系统只使用合法资料和团队原创整理内容生成资源，不复制出版教材原文，不处理教材 PDF 或扫描件，不要求模型复述教材正文。
