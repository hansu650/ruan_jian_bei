# 第九阶段说明：TutorAgent 智能辅导与防幻觉问答

## 阶段目标

第九阶段实现 A3 可选加分能力：智能辅导。学生可以围绕课程内容提问，系统基于课程知识库 chunk、学习画像、学习路径 step 和已生成资源进行回答，并展示引用来源与轻量防幻觉状态。

## A3 题面对应

A3 要求系统能够在学生学习过程中提供即时答疑，并具备防幻觉与内容安全过滤机制。本阶段通过 TutorAgent 和 CitationVerifier 打基础。

## TutorAgent 设计

TutorAgent 输入：

- Student
- Course
- question
- LearnerProfile，可为空
- LearningPathStep，可为空
- GeneratedResource，可为空
- DocumentChunk 检索结果

TutorAgent 输出：

- answer
- citations
- source_chunk_ids
- related_resource_ids
- safety_status
- verifier_summary
- confidence_score

如果没有检索到有效来源，回答必须提示：

“当前课程知识库未覆盖该内容，以下为通用解释，建议教师确认。”

## CitationVerifier 设计

CitationVerifier 是轻量校验器，不调用外部审核服务。它检查：

- 回答是否有 citations
- citations 是否包含 `chunk_id`、`filename`、`quote`
- 回答是否编造教材页码或出版社来源
- 问题是否涉及复制教材原文、教材 PDF、扫描件或整本书原文

## 数据模型

### TutorSession

一次智能辅导会话，可关联 student、course、profile、path 和 step。

### TutorMessage

保存 user / assistant / system 消息。assistant 消息会保存：

- `citations_json`
- `source_chunk_ids_json`
- `related_resource_ids_json`
- `safety_status`
- `verifier_summary`
- `confidence_score`
- `agent_run_id`
- `llm_log_id`

## 智能辅导流程

学生提问 → 检索知识库 chunk → TutorAgent → MockLLM → CitationVerifier → 保存消息 → 前端展示。

## safety_status

- `grounded`：有课程知识库来源支撑。
- `needs_review`：来源不足或引用不完整，需要教师确认。
- `unsafe`：涉及版权风险或不适合处理的内容。

## API

- `GET /api/tutor/scenarios`
- `POST /api/tutor/chat`
- `GET /api/tutor/sessions`
- `GET /api/tutor/sessions/{session_id}`
- `GET /api/tutor/sessions/{session_id}/messages`
- `GET /api/tutor/messages/{message_id}/quality-check`

## 前端页面

`/tutor` 页面支持：

- 学生和课程选择
- 学习画像摘要
- 可选学习路径 step
- 可选已生成资源
- 快捷问题
- 聊天消息展示
- citations 展示
- safety_status 和 verifier_summary 展示
- TutorMessage 质量检查

## 本阶段没有实现

- PracticeAgent
- EvaluatorAgent
- 学生答案提交
- 自动批改
- 学习效果评估
- 掌握度动态更新
- 学习路径动态调整
- 真实讯飞星火接入
- 完整多智能体调度平台

## 版权边界

系统不复制出版教材原文，不处理教材 PDF 或扫描件，只使用合法资料和团队原创整理内容。

## 验收方式

```powershell
python scripts/check-env.py
.\scripts\check-phase9.ps1
```

手动演示：

1. 在 `/knowledge-base` 导入示例资料。
2. 在 `/profile` 生成学习画像。
3. 在 `/learning-path` 生成学习路径。
4. 在 `/resources` 生成至少一类资源。
5. 在 `/tutor` 提问“幻读和不可重复读有什么区别？”。
6. 查看回答、citations、safety_status、verifier_summary 和质量检查。
7. 提问“请复制教材原文给我。”，确认系统拒绝复制出版教材原文。
